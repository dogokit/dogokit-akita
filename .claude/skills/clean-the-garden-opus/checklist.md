# Gardening round checklist

- [ ] Read agent instruction files, lint/type/test config, shared helpers
- [ ] Run type checker and linter, read hints and warnings too
- [ ] Unused code: exports, styles, config keys, old-runtime fallbacks
- [ ] Comments: stale, contradicting, workaround-blessing, restating
- [ ] Hand-rolled copies of shared code (links, constants, ranges)
- [ ] For each bug found, grep the whole repo for the same shape
- [ ] Copied defaults nobody chose
- [ ] Dead links and outdated docs
- [ ] Tag each weed: copy / new from later work / old and missed
- [ ] Fix on the spot; short write-up per change
- [ ] Guard each recurring weed: design > check > written rule beside code
- [ ] Report fixes, guards, uncovered gaps, unfixed findings
