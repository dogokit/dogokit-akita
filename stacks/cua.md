# Cua

Cua is open-source infrastructure for computer-use agents, with sandboxed desktops for macOS and Linux, an SDK, and tools to test agents. It is here as a sandbox option next to [agent-desktop](agent-desktop.md) for AI Computer Use

Official links:

- [Cua](https://cua.ai): official site
- [Cua Docs](https://cua.ai/docs): official docs
- [Cua GitHub](https://github.com/trycua/cua): source code, MIT for most of the repo, with Cua Spaces under FSL-1.1-MIT
