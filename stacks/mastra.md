# Mastra

Mastra is a TypeScript framework for AI agents and apps, here for AI orchestration with agents, tools, workflows, memory, and evals in one package. Its Mastra Factory runs coding agents from issue to pull request, with humans approving plans and merges

Official links:

- [Mastra](https://mastra.ai): official site
- [Mastra Docs](https://mastra.ai/docs): official docs
- [Mastra Factory](https://mastra.ai/factory): official Mastra Factory page
- [Mastra Factory Docs](https://factory.mastra.ai): official Factory docs
- [Mastra GitHub](https://github.com/mastra-ai/mastra): source code, Apache-2.0 for the core, with an enterprise license for `ee/` code
