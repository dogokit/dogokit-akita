# Mastra

Mastra is a TypeScript framework for building AI agents and apps. It is here for AI orchestration, with agents, tools, workflows, memory, and evals in one package

Official links:

- [Mastra](https://mastra.ai): official site
- [Mastra Docs](https://mastra.ai/docs): official docs
- [Mastra GitHub](https://github.com/mastra-ai/mastra): source code, Apache-2.0 for the core, with an enterprise license for `ee/` code
