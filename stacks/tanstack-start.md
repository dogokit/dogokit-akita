# TanStack Start

TanStack Start is a full-stack React framework built on TanStack Router. It handles server rendering, streaming, and server functions, so the app can run its server code with type-safe calls. It is here as the full-stack option for React apps.

Official links:

- [TanStack Start](https://tanstack.com/start): official site
- [TanStack Start Docs](https://tanstack.com/start/latest/docs): official docs
- [TanStack Router GitHub](https://github.com/TanStack/router): source code, MIT (Start lives in this repo)
