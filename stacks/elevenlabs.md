# ElevenLabs

ElevenLabs is an AI voice platform. It turns text into speech, clones voices, turns speech into text, and runs voice agents. It is here as an AI audio tool for voice output

Official links:

- [ElevenLabs](https://elevenlabs.io): official site
- [ElevenLabs Docs](https://elevenlabs.io/docs/overview): official docs
- [ElevenLabs JavaScript SDK](https://github.com/elevenlabs/elevenlabs-js): official JavaScript SDK source code, MIT
- Package: `@elevenlabs/elevenlabs-js` on npm (JavaScript) and `elevenlabs` on PyPI (Python)
