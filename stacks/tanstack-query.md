# TanStack Query

TanStack Query manages async server state in React. It caches data, removes duplicate requests, retries failed calls, refetches in the background, and handles mutations.

- [TanStack Query](https://tanstack.com/query): official site
- [TanStack Query Docs](https://tanstack.com/query/latest/docs): official docs
