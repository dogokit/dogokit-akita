# Modern Web Guidance

Agent skills from the Chrome team at Google. They help your coding agent write current web code, such as modern HTML and CSS features, instead of older patterns, and match your browser support target

Install with `npx modern-web-guidance@latest install`. The CLI route turns on automatic updates. If no Baseline target is set, it uses Baseline Widely available, the web features that work in all major browsers

Official links:

- [Modern Web Guidance docs](https://developer.chrome.com/docs/modern-web-guidance): official docs
- [Modern Web Guidance GitHub](https://github.com/GoogleChrome/modern-web-guidance): the skills package, Apache-2.0 license
- [Modern Web Guidance source](https://github.com/GoogleChrome/modern-web-guidance-src): source for writing and testing the guides, Apache-2.0 license
