# TanStack Router

TanStack Router is a type-safe router for React. The route tree sets the paths, params, search state, loaders, and links. It is the routing layer that TanStack Start uses.

Official links:

- [TanStack Router](https://tanstack.com/router): official site
- [TanStack Router Docs](https://tanstack.com/router/latest/docs): official docs
- [TanStack Router GitHub](https://github.com/TanStack/router): source code, MIT
