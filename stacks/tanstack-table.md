# TanStack Table

TanStack Table is a headless engine for tables and data grids. It handles sorting, filtering, pagination, grouping, row selection, and pinning. It does not render markup or styles, so you write the UI yourself.

Official links:

- [TanStack Table](https://tanstack.com/table): official site
- [TanStack Table Docs](https://tanstack.com/table/latest/docs): official docs
- [TanStack Table GitHub](https://github.com/TanStack/table): source code
