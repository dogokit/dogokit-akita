# Zeabur

Zeabur is a cloud platform that deploys your apps and services with little setup. It builds your project from a GitHub repo, a Dockerfile, or a Docker image, so you skip server and CI/CD work. It is an option for the General deployment slot, next to Railway

Official links:

- [Zeabur](https://zeabur.com): official site
- [Zeabur Docs](https://zeabur.com/docs): official docs
- [Zeabur GitHub](https://github.com/zeabur/zeabur): source code of the platform, MPL-2.0
- [Zeabur CLI](https://github.com/zeabur/cli): official command line tool, MPL-2.0
