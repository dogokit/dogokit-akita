# open-slide

open-slide is a slide framework built for AI coding agents. You describe a deck, and the agent writes each slide as a React component on a fixed 1920 × 1080 canvas. It is here as the slide tool for decks made with an AI agent

Official links:

- [open-slide](https://open-slide.dev): official site
- [open-slide Docs](https://open-slide.dev/docs): official docs
- [open-slide GitHub](https://github.com/open-slide/open-slide): source code, MIT license
- Package: `@open-slide/cli`
