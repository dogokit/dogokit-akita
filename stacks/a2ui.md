# A2UI

A2UI (Agent-to-User Interface) is an open-source framework for generative UI. An agent streams a screen layout as data, and the app draws it with its own native components in React, Angular, Lit, Flutter, SwiftUI or Jetpack Compose. Use it when an agent should build parts of a screen, not only send text

- Package: `@a2ui/react`, `@a2ui/lit` and `@a2ui/angular` on npm

Official links:

- [A2UI](https://a2ui.org): official site
- [A2UI Quickstart](https://a2ui.org/quickstart/): official docs
- [A2UI GitHub](https://github.com/a2ui-project/a2ui): source code, Apache-2.0 license
