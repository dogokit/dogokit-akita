# Vite+

Vite+ is a unified web toolchain from VoidZero, run through one CLI called `vp`. In this stack it covers the dev server, tests, lint, format, build, and manages the runtime and package manager.

Official links:

- [Vite+](https://viteplus.dev/): official site
- [Vite+ Docs](https://viteplus.dev/guide/): official docs
- [Vite+ GitHub](https://github.com/voidzero-dev/vite-plus): source code, MIT license
- Package: `vite-plus`
