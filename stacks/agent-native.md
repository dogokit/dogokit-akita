# Agent Native

Agent Native is an open-source TypeScript framework for building apps where an AI agent and the UI share the same database, actions and app state. It is here as an option beside Mastra for agent-driven apps

Official links:

- [Agent Native](https://agent-native.com): official site
- [Agent Native Docs](https://agent-native.com/docs): official docs
- [Agent Native GitHub](https://github.com/BuilderIO/agent-native): source code, MIT license
- Package: `@agent-native/core`
