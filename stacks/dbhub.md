# DBHub

Open-source MCP server that connects an AI assistant to your databases. Its site describes it as minimal and token-efficient. It is made by Bytebase.

- Package: `@bytebase/dbhub`

Links:

- [DBHub](https://dbhub.ai): official site
- [DBHub GitHub](https://github.com/bytebase/dbhub): source code, MIT license
- [DBHub Quickstart](https://dbhub.ai/quickstart.md): setup guide
