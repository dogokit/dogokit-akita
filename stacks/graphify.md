# Graphify

Turns a folder of code, docs, papers, images or videos into a knowledge graph that agents can query. This repo uses it as a local map for AI coding agents.

Install with `uv tool install graphifyy` or `pip install graphifyy`. The package name has two y's.

Use `/graphify` in Claude Code to build the graph. Output goes to `graphify-out/`, which is git-ignored. Build it once per worktree.

Links:

- [Graphify on GitHub](https://github.com/Graphify-Labs/graphify): source, docs and issues
