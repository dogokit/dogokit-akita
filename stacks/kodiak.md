# Kodiak

GitHub bot that updates and merges pull requests for you. Once a PR is approved and checks pass, Kodiak merges it

Official links:

- [Kodiak](https://kodiakhq.com): official site
- [Kodiak Quickstart](https://kodiakhq.com/docs/quickstart): official docs
- [Kodiak GitHub](https://github.com/chdsbd/kodiak): source code, AGPL-3.0
