# TanStack AI

TanStack AI is a TypeScript library for building AI chat features and agents. It includes an agent loop, provider adapters, tools, persistence, and streaming. It is here as the AI option in the TanStack family.

Official links:

- [TanStack AI](https://tanstack.com/ai): official site
- [TanStack AI Docs](https://tanstack.com/ai/latest/docs): official docs
- [TanStack AI GitHub](https://github.com/TanStack/ai): source code, MIT
