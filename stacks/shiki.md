# Shiki

Syntax highlighter for code blocks. It uses the same grammars and themes as VS Code, so code looks the same as in the editor

Official links:

- [Shiki](https://shiki.style): official site and docs
- [Shiki Guide](https://shiki.style/guide): getting started
- [Shiki GitHub](https://github.com/shikijs/shiki): source code, MIT
- Package: `shiki`
- Latest version: v4.6.0

Do not use the old `shiki.matsu.io` address. Use `shiki.style`
