# Pages CMS

Pages CMS is an open-source CMS for static sites stored in GitHub repositories. Editors change the site's content in a web app, and the changes are saved back to the repo as files.

Official links:

- [Pages CMS](https://pagescms.org): official site
- [Pages CMS Docs](https://pagescms.org/docs): official docs
- [Pages CMS GitHub](https://github.com/pages-cms/pages-cms): source code, MIT license
