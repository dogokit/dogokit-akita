# React Helmet

React Helmet Async manages the document head (title, meta tags, links) from React components, so each page can set its own SEO tags without a framework.

- Package: `react-helmet-async`
- Latest version: v3.1.0
- Works with React 19 and server-side rendering

The original `react-helmet` package is no longer actively maintained, so use `react-helmet-async` for new projects.

Links:

- [react-helmet-async](https://github.com/staylor/react-helmet-async): maintained fork
- [react-helmet](https://github.com/nfl/react-helmet): original package, unmaintained
