# Trail

Trail is a two part product from the same company: a company brain for AI agents, and an open-source memory layer for coding agents. This note covers both, in separate sections.

## Trail

Trail turns policies, procedures and know-how from people's heads into one shared brain. Each rule cites its source, so Claude, ChatGPT and your own agents give the same answer.

Official links:

- [Trail](https://trailhq.com): official site

## Trail-code

Trail-code is shared memory for coding agents. It is stored in your repo and synced with git. Install it with `npm install -g @trailhq/trail-code`, then run `trail init`.

Official links:

- [Trail-code](https://trailhq.com/trail-code): official product page
- [Trail-code GitHub](https://github.com/trailhq/Trail-Code): source code, MIT license as stated on the product page
- Package: `@trailhq/trail-code`
