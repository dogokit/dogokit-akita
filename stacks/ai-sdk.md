# AI SDK

AI SDK is a TypeScript toolkit for building AI apps and agents. It gives one API for text and structured output, tool calls, and streaming across many model providers, and works with React, Next.js, Vue, Svelte, and Node.js.

Official links:

- [AI SDK](https://ai-sdk.dev): official site
- [AI SDK Docs](https://ai-sdk.dev/docs): official docs
- [AI SDK GitHub](https://github.com/vercel/ai): source code, Apache 2.0
- Package: `ai` on npm
