# agent-desktop

A Vercel Labs CLI that gives an AI agent computer use. It reads the accessibility tree of desktop apps on macOS, Windows and Linux, so the agent works from JSON refs, not screenshots. Use it when an agent must drive a desktop app, not only a web page

- Package: `agent-desktop` on npm
