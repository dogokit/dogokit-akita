# NestJS

Progressive TypeScript framework for building server apps on Node.js. It uses modules, decorators and dependency injection, so the code stays organized as the app grows

## HTTP client

Use `@nestjs/http-client` for HTTP calls in new code. It is built on the `fetch` API that ships with Node.js and replaces the Axios-based `HttpModule` from `@nestjs/axios`. `@nestjs/axios` stays available for existing code

- Package: `@nestjs/http-client`
- Use it instead of `HttpModule` from `@nestjs/axios`
