# Web

Default:

- Language: TypeScript
- Runtime: Bun
- Framework: React
- Styling: Tailwind CSS
- UI Components: shadcn/ui
- API: tRPC
- Auth: Better Auth
- Forms: Conform / React Hook Form
- Validation: Zod

Extended:

- Unit Testing: Vitest
- E2E Testing: Playwright
- Documentation: Storybook
- Client-State Management: TanStack Query

## Example

A minimal web page lives here. It imports `greet` from [`packages/utils`](../../packages/utils/README.md) and is not a real app

- Dev server: `vp run @dogokit/web#dev`
- Build: `vp run @dogokit/web#build`
